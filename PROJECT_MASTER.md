## Development Rules
1. Read the project files before changing anything.
2. Make small, testable changes.
3. Explain every change clearly.
4. Never delete existing work without approval.
5. Never commit passwords, API keys, or private secrets.
6. Test each feature before marking it complete.
7. Document bugs and unfinished tasks.
