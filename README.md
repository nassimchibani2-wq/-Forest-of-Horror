# Forest of Horror

An AI-assisted horror game project planned for mobile and PC.

## Vision
Create an immersive horror experience featuring exploration, suspense, dangerous creatures, and atmospheric environments.

## Target Platforms
- Mobile
- PC

## Development Roadmap
- 2027: Project design and first playable prototype.
- 2028: Gameplay systems, levels, monsters, and optimization.
- 2029: Mobile testing, polishing, and planned release.
- 2030: PC adaptation, testing, and planned release.

## Current Status
Project setup and documentation.

## Development Principles
- Protect existing work.
- Test changes before accepting them.
- Never publish passwords or API secrets.
- Track bugs and unfinished features.
- Treat release dates as targets, not guarantees.
